# 02 · 文档整理

## 放什么

- 文件与目录命名规范
- 组会纪要、实验记录、周报模板
- 文献库索引与 BibTeX 入口

## 不放什么

- 原始数据、论文正文、大体积二进制文件

## 子目录

| 路径 | 用途 |
| --- | --- |
| [`naming.md`](naming.md) | 命名规范，新建任何文件前先看 |
| [`templates/`](templates/) | 纪要 / 实验记录 / 周报模板 |
| `literature/` | 文献索引（待建） |

## 为什么值得先写命名规范

搜不到文件，比没有文件更浪费时间。你现在可能对 `最终版_v2_改完.docx` 能一眼认出，但三个月后不行，共享给合作者更不行。

命名规范的目的不是好看，是**让你能用搜索代替回忆**。

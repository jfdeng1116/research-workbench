# 文件命名规范

## 基本格式

```
YYYYMMDD_对象_内容_版本.扩展名
```

例子：

```
20261119_宇航学报_引言初稿_v1.tex
20261119_路由组会_纪要_v1.md
20261119_LEO星座仿真_结果对比_v3.xlsx
```

日期在前，排序就是时间线，不需要再建「旧文件」目录。

## 禁止写法

| 不要用 | 原因 |
| --- | --- |
| `最终版` `最终版2` `真最终` | 没有终点，最后全叫最终版 |
| `新建文档` `未命名` | 零信息 |
| `副本` `copy` | 不知道副本差异 |
| `改` `修改后` | 不知道改了什么 |
| 空格、`#`、`&`、中文括号 | 跨平台/命令行/LaTeX 到处出问题 |

## 版本号

- `v1` `v2` `v3`：**内容有实质变化**才加
- 只改错别字、调格式：不加版本，直接覆盖
- 对外发送或投稿的版本：加后缀 `_submitted` / `_final`，并把这个文件单独拷出来存档

## 目录层级

建议不超过三层。第四层通常意味着分类维度错了——把文件拆散不如把文件名写清。

```
项目/
├─ 01-文献/
├─ 02-数据/
├─ 03-代码/
└─ 04-文稿/
```

## 命名里的缩写

只用 `glossary.md` 里收录的缩写。自创缩写会在半年后变成一个又一个小谜题。

# 投稿前检查清单

> 交稿前一天逐项打勾。建议复制一份到论文目录里再勾，不要直接改本文件。
> 各刊具体要求以官方投稿须知为准，本清单只盖通用项。

## 一、结构与逻辑

- [ ] 摘要能独立读懂：目的、方法、结果、结论四要素齐备
- [ ] 引言说清了「别人做了什么 → 还差什么 → 本文做什么」三段递进
- [ ] 每个图表在正文中都被引用，且引用位置在首次讨论处附近
- [ ] 结论里的每个数字都能在正文或图表中找到出处
- [ ] 没有「首次提出」「国内外首创」这类无法证明的表述

## 二、语言

- [ ] 术语全文一致，与 `glossary.md` 对得上
- [ ] 缩写首次出现给全称，后文不冉展开
- [ ] 中文句子用中文句号（。），不与英文句点（.）混用
- [ ] 图题、表题、摘要、正文的标点风格统一
- [ ] 长句拆短：单句超过 60 字的逐个检查
- [ ] 通读一遍，重点找「的地得」、主谓缺失、指代不明

## 三、图表

- [ ] 图内字体不小于 7 pt，缩印后仍可读
- [ ] 矢量图优先（PDF/EPS），位图分辨率 ≥ 300 dpi
- [ ] 坐标轴有量纲和单位，图例清晰不遮挡数据
- [ ] 表题在上、图题在下（多数中文刊惯例）
- [ ] 表格用三线表，不用 Excel 截图
- [ ] 灰度打印后仍能区分不同曲线（用线型而非仅用颜色）

## 四、公式与符号

- [ ] 全文符号在首次出现处定义，且不重复定义
- [ ] 变量斜体、矩阵粗体、单位正体
- [ ] 公式编号连续，正文引用写「式(3)」而非「式3」
- [ ] 多行公式对齐，标点在式末而非行中

## 五、参考文献

- [ ] 按 GB/T 7714 格式（或目标刊要求）统一
- [ ] 中文文献保留中文，不强行翻译成英文
- [ ] 每条都有 DOI 或可检索信息
- [ ] 近五年文献占比合理，经典工作不遗漏
- [ ] 自引适度，不自引堆数量
- [ ] 正文引用序号与文后列表一一对应

## 六、格式与材料

- [ ] 中英文摘要、关键词、中图分类号齐备
- [ ] 基金项目编号、作者简介、通信作者标注无误
- [ ] 图文件单独打包（若期刊要求）
- [ ] 查重率在期刊阈值以下
- [ ] 投稿信（cover letter）写清了创新点与推荐理由
- [ ] 作者顺序与单位已征得全体作者同意

## 七、送审前自查

- [ ] 把论文当别人的文章读一遍，能否在 10 分钟内抓住贡献
- [ ] 模拟审稿人提问：方法为什么合理？对比基线公平吗？
- [ ] 实验可复现信息写全（参数、版本、数据来源）

# 审稿意见逐条回复

## 提示词

```
下面是一条审稿意见和我的初步想法。请把它整理成回复函体：

结构固定为：
【审稿意见】原文本
【回应】接受 / 部分接受 / 不接受（先亮态度，不绕）
【修改说明】在正文第 X 节做了什么具体改动，引原文改动后的句子
【理由】若不接受，给出文献或实验依据

约束：- 不写「感谢专家宝贵意见」超过一句的套话；
- 不回避问题，不为难处找诗；
- 我没提供依据的地方标「[需补实验/需补文献]」，不要自己编。

审稿意见：...
我的想法：...
```

## 态度比文笔重要

审稿人最反感两类回复：一是长篇感谢但不改；二是改了但不说改在哪。
一条意见一段，每段里必须能找到「第几节第几行改成了什么」。

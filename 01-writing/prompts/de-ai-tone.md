# 去除 AI 味与模板化表达

## 提示词

```
下面是一段论文文字。请先不要改写，先完成两件事：
1. 逐句标出读起来像机器生成的地方，并说明原因（空洞套话、过度对称、
   万金油连接词、无信息量的限定语）。
2. 指出哪些句子存在「不是 X，而是 Y」这类假对立结构。

然后才改写。改写要求：
- 每句不超过 40 字；
- 删掉「值得注意的是」「综上所述」「随着…的发展」这类开头；
- 保留原意和所有数据，不得自行补充论据；
- 不确定的地方标注「[待确认]」，不要编。

原文：
...
```

## 常踩的坑

| 现象 | 改法 |
| --- | --- |
| 三段式排比堆砌 | 只留信息量最大的一段 |
| 「显著提升」「大幅优化」 | 直接给百分比 |
| 每段首句都是总分结构 | 打乱，让段落有自己的开口 |
| 结尾必升华 | 删。结论只回答引言提的问题 |

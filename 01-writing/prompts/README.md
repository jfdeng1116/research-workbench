# 写作提示词库

每个提示词一个 `.md` 文件，命名 `用途-场景.md`。提示词里的「你要检查…」比「你是一个资深专家」有用得多。

## 已有

| 文件 | 用途 |
| --- | --- |
| `polish-abstract.md` | 摘要压缩与重构 |
| `de-ai-tone.md` | 去除机械感、模板化表达 |
| `review-response.md` | 审稿意见逐条回复草稿 |
| `consistency-check.md` | 术语与符号一致性检查 |

## 写好提示词的三个要点

1. **给它具体约束，不是角色**。「你是顶级学者」不产生任何效果；「每句不超过 40 字，禁用『值得注意的是』『综上所述』」才会。
2. **要求它先指出问题再改写**。只让它改，它会默默把意思改至。
3. **要它标出不确定处**。宁可它说「这句主语不明」，也不要它自作主张补一个主语。

## 一条使用红线

AI 帮你润色语言可以，但**判断、结论、创新点必须是你自己的**。提示词里不要让它「补充实验分析」或「推测可能的结论」——那是在造数据。

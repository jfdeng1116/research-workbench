# 01 · 学术写作

## 放什么

- 各刊 LaTeX / Word 模板
- 中英术语与符号统一表
- 投稿前逐项检查清单
- 可复用的写作与润色提示词

## 不放什么

- 论文正文草稿、未发表的实验结果、审稿意见原文

## 子目录

| 路径 | 用途 |
| --- | --- |
| [`journal-templates/`](journal-templates/) | 按期刊分目录存放排版模板 |
| [`glossary.md`](glossary.md) | 术语 / 缩写 / 符号统一表 |
| [`prompts/`](prompts/) | 润色、去 AI 味、审稿回复的提示词 |
| [`submission-checklist.md`](submission-checklist.md) | 交稿前逐项打勾 |

## 一条硬规矩

**同一概念只能有一种译法。** 新术语先写进 `glossary.md`，再进正文。论文里出现 `glossary.md` 未收录的写法，一律当作笔误处理。

这条规矩比模板重要得多。审稿人往往不会因为模板不漂亮拒稿，但会因为「同一个东西在第三章叫路由算法、第四章叫路由选择策略」而认为作者不严谨。

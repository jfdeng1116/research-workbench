# 03 · 演示文稿

## 放什么

- 答辩 / 组会 / 学术会议 PPT 模板
- 可复用的图表、矢量图、配色定义
- 汇报结构提纲

## 不放什么

- 大体积视频、录屏、幻灯片导出 PDF

## 子目录

```
03-slides/
├─ templates/     # 按场景分：defense/ seminar/ conference/
└─ assets/        # logo、配色、可复用矢量图
```

## 三个场景的版式差异

| 场景 | 页数 | 重点 |
| --- | --- | --- |
| 学位答辩 | 25–35 | 完整叙事，方法细节不能省 |
| 组会汇报 | 10–15 | 进度 + 卡在哪里 + 下一步 |
| 学术会议 | 12–18 | 一页一个结论，公式能删就删 |

## 技术约定

- 16:9，中文字体用黑体 / 思源黑体，**不用宋体做标题**（投影发糊）
- 图一律导出矢量 PDF 或 300 dpi PNG，不直接截图
- 公式用 PowerPoint 自带公式编辑器，不贴 LaTeX 渲染图
- 字体嵌入文件，否则换电脑必乱

## 经验

答辩 PPT 最常被问倒的不是创新点，而是「你这个参数为什么取这个值」。提前把每个超参的来源页做一张备用幻灯片放在附录。
